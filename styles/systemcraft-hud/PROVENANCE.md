# Provenance — systemcraft-hud

## Origin

- **Authored:** 2026-10-21, for the Overmind Gateway.
- **Author:** Nikolche / PixelWeave, with Fenix.
- **Status:** ready; used by the Overmind Gateway as the third style.
- **Name:** “systemcraft” is a working systems/HUD label. It is not an
  affiliation with StarCraft, Blizzard Entertainment or any other game.

This style is a deliberate hybrid of two earlier original styles in this
library:

- **moderncraft-hud** — near-black card screens, restrained chrome, the 45°
  accent hatch, accent-driven card borders and hover rings.
- **mechcraft-hud** — Saira Condensed display type, 3–6 px card geometry, inset
  highlights, technical labels, compact numeric/data treatment.

The combination, the darker neutral ramp, the three-colour role system, the
six role orders, the combined masthead, the Sahara/grid background switch and
the new component recipes are original work for this style.

No third-party component library, template, theme file, screenshot, logo,
portrait, unit art, icon set or extracted texture is included. The two source
styles are themselves original CSS/token work in this library.

## Excluded assets

The Overmind application header uses a separate third-party StarCraft Command
Center wireframe for personal/LAN use. It is **not** part of this style and is
not included in this directory. Replace it with an original mark before public
distribution. No Overmind branding or Command Center artwork appears in
`theme.css`, `tokens.json`, `demo.html` or `preview.png`.

The role names (amber, cyan, lime) are colour names only. The style is
brand-neutral and reusable by any project.
